Cómo obtener la llave de GitHub (token)
  1. Abre este enlace de GitHub (ya viene casi todo lleno: nombre, dueño usa-shoes, sin vencimiento y permiso «Contents: Read and write»).
  2. En Repository access marca «Only select repositories» y elige usa-shoes.github.io.
  3. Pulsa «Generate token», cópialo (empieza por github_pat_) y pégalo abajo.
  4. Luego escribe el usuario y la contraseña que tú quieras para entrar a esta administración.

La llave se guarda cifrada con tu usuario y contraseña. Sin ellos nadie puede usarla. Si olvidas la contraseña, crea una llave nueva y repite este paso.
